# V6.8 科学记忆与复习方案

> 版本：V6.8 · 2026-10
> 前置：V6.6 生词本、V6.7 学习资料中心与间隔复习（均已交付）
> 范围：艾宾浩斯遗忘曲线排期改造 + 生词发音（🔊）+ 复习统计 + TTS 朗读语言跟随与语速

## 1. 背景与问题

V6.7 的复习排期是"简单盒子"：`[1, 3, 7, 14, 30]` 固定间隔、**遗忘即归零**。
三个不够"科学"的地方：

1. **间隔序列**：1/3/7/14/30 是拍的，不是艾宾浩斯经典记忆周期
   （1 天 / 2 天 / 4 天 / 7 天 / 15 天 / 1 个月）。
2. **遗忘归零**：艾宾浩斯曲线下"忘了"≠"记忆清零"——留存是指数衰减，
   忘了的人从零重爬 30 天太惩罚（Anki SM-2 的 lapse 也走 relearning 而非重新学）。
3. **无反馈**：看不到"这个词我大概还记得几成"、"我坚持复习了几天"，
   复习行为没有正反馈，难以坚持。

同期两个"听得见"缺口：TTS 朗读硬编码 `zh-CN`（英文书用中文引擎念英文），
生词复习/查词没有发音。

## 2. 艾宾浩斯遗忘曲线怎么加入（核心设计）

### 2.1 复习周期序列（日粒度）

经典艾宾浩斯记忆周期的复习节点：5 分钟、30 分钟、12 小时、1 天、2 天、4 天、
7 天、15 天、1 个月。**阅读器场景用户不会为 5 分钟后的复习回到 App**，
分钟级节点不实用；取其日粒度骨架：

```
EBBINGHAUS_INTERVAL_DAYS = [1, 2, 4, 7, 15, 30]   // 6 级
```

- 复习满 6 级 = 走完全部周期 → **毕业**（进入长期记忆），
  此后按 90 天一次的"维护间隔"低频出现（也可视为不再打扰）。
- 字段不变（`reviewStep / dueAt / lastReviewedAt`，仍挂 vocab 记录，DB 保持 v7）：
  V6.7 老数据的 `reviewStep` 语义一致（第几级），序列变了但无需迁移；
  已毕业语义 = `reviewStep >= 6`，老数据到 5 级封顶的会在下次"记住了"后自然毕业。

### 2.2 记住 / 忘记的排期规则（纯函数 `reviewVocabRecord`）

| 动作 | 级别变化 | 下次到期 | 依据 |
| --- | --- | --- | --- |
| 记住了 | `step + 1`（封顶 6 = 毕业） | `now + interval[旧step]` 天 | 沿周期爬一级 |
| 忘了 | `max(step - 2, 0)`（**回退 2 级，不归零**） | **明天**（now + 1 天） | 留存衰减但未清零：退 2 级保住"从最近稳固节点重爬"的科学性，明天再见面保住 V6.7 的"次日重试"体验 |

### 2.3 记忆留存率展示（纯函数 `retentionEstimate`）

用艾宾浩斯留存公式做**展示级估算**（不是调度依据，调度仍走固定周期——
可解释、可预期，比黑盒算法更适合个人工具）：

```
R(t) = e^(-t / S)
t = now - lastReviewedAt（天，未复习过的新词按收藏时刻起算）
S = 当前级别的间隔天数（step 0 且从未复习 → S = 1；毕业 → S = 90）
```

生词卡显示"记忆强度 ≈ 87%"。刚复习完 ≈ 100%，30 天级别的词衰减极慢——
数字给用户"哪些词快忘光了"的直觉，也解释了为什么要赶在到期前复习。

### 2.4 数据模型

不升库。`VocabRecord` 既有 `reviewStep / dueAt / lastReviewedAt` 三字段够用；
毕业判定用派生函数 `isVocabMastered`（`reviewStep >= EBBINGHAUS_INTERVAL_DAYS.length`）。

复习活动统计复用 `stats` store：`DayStatRecord` 增加可选字段
`reviews?: number`（旧记录无此字段视作 0，IndexedDB value 无 schema，免升库）。

## 3. 生词发音（🔊）

新 `core/speech.ts`（浏览器 Web Speech 薄封装 + 可单测的语言选择纯函数）：

- `pickSpeechLang(text)`：复用 `looksChinese`——中文词 `zh-CN`，西文 `en-US`；
- `speakText(text, { rate })`：先 `cancel()` 再 `speak()`（连续点按钮不叠音）；
  语速取全局设置 `ttsRate`；不支持 Web Speech 的环境静默降级；
- `stopSpeaking()`：离开页面/翻页时停。

入口两处：学习资料中心的生词卡（词旁 🔊 按钮）；阅读页翻译浮卡
（`tr-actions` 增加"🔊 读音"，念选中的词/句）。

## 4. 复习统计入口

纯函数 `summarizeReview(vocabRecords, reviewDays, now)`（core/studyMaterials.ts）：

| 指标 | 口径 |
| --- | --- |
| 今日到期 N | `isVocabDue && !mastered` 的生词数（跨书全局） |
| 已掌握 M | `reviewStep >= 6`（走完艾宾浩斯周期） |
| 连续复习 K 天 | `stats` 里 `reviews > 0` 的日期，从今天（今天没复习则从昨天）往回连续计数 |

仓储层：`reviewVocab()` 成功后顺带 `stats.reviews + 1`（同一动作两笔小记录）；
新增 `listReviewDays()` 返回有复习活动的日期串列表。
UI：学习资料中心标题下一行统计条。

## 5. TTS 朗读语言跟随 + 语速

- `ReaderSettings.ttsRate`：档位 `[0.75, 1, 1.25, 1.5, 2]`，默认 1；
  settings 读写兼容旧数据（非法值回退默认）。
- ReaderPage 打开书时确定朗读语言：EPUB 用 `book.language`，
  其余格式用 `looksChinese` 抽样正文判断 → `u.lang`；`u.rate = ttsRate`。
- 设置页新增"朗读语速"档位 chips（轻量更新，不触发重排）。

## 6. 验收标准

| # | 验收 |
| --- | --- |
| 1 | 记住：1→2→4→7→15→30 天递进，第 6 级后毕业不再出现在"只看待复习" |
| 2 | 忘了：级别回退 2 级（不归零）、明天到期 |
| 3 | 记忆强度百分比随时间衰减、复习后回满，数学正确（单测） |
| 4 | 统计条：到期数/掌握数/连续天数正确；断档一天连续数归零重计 |
| 5 | 英文书朗读用英文语音、中文书用中文语音；语速档位生效且重启保持 |
| 6 | 生词卡与翻译浮卡可发音；连续点击不叠音；不支持的环境不报错 |
| 7 | V6.7 老数据（1/3/7/14/30 的 step）无需迁移即可继续复习 |
| 8 | 全部测试通过、tsc/vite build 通过 |

## 7. 不做清单（克制）

- **SM-2/FSRS 全算法**：参数调度黑盒化，个人工具要的是"可预期"，固定周期 + 回退足够；
  留存率公式只做展示。
- **分钟级复习节点**（5min/30min/12h）：阅读器场景不实用，成本高收益低。
- **复习提醒通知**：PWA Notification 权限打扰，待统计功能验证粘性后评估。
- **TTS 逐句混语**（中英混排每句切语言）：utterance 队列复杂度陡增，书级语言已覆盖主场景。
