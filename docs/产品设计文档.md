# xifeng 阅读 · 产品设计文档（MVP）

## 1. 产品定位

一款 **本地 TXT 电子书阅读器**（Web 应用）。

- 目标用户：有本地 TXT 小说/文本阅读需求的用户，重点是长篇内容的舒适阅读。
- 核心价值闭环：**导入一本书 → 舒服地读完 → 下次打开接着读**。
- 形态：先做 Web 应用；未来如需"双击本地文件直接打开"的桌面体验，再用 Tauri 等方案包装。

## 2. MVP 功能范围（P0）

| 功能 | 说明 |
| --- | --- |
| 书籍导入 | 本地 TXT 文件导入（文件选择 / 拖拽） |
| 编码识别 | 自动识别 UTF-8 / GBK / GB18030，杜绝中文乱码 |
| 书库 | 平铺列表，展示书名、阅读进度、最后阅读时间；支持删除书籍 |
| 阅读页 | 分页显示；上一页 / 下一页；字号、行距可调；明亮主题 |
| 进度记忆 | 自动保存每本书的阅读位置，重新打开自动续读 |
| 进度跳转 | 底部进度条，可拖动跳转到任意位置（无目录场景下的最低限度导航） |

## 3. 非目标（本期明确不做）

- EPUB / PDF 等其他格式
- 目录与章节切分
- 深色 / 护眼主题（仅明亮主题）
- 书签、划线笔记
- 全文搜索
- 账号与云同步
- TTS 朗读、在线书源

## 4. 关键设计要点

- **编码识别**：中文网络 TXT 大量使用 GBK/GB18030 编码，需按字节特征探测，不能假设 UTF-8。这是"支持 TXT"定义的一部分，不是附加功能。
- **大文件**：几 MB 的 TXT 是常态，禁止全文一次性渲染进页面；采用分块/懒加载策略，架构上第一版就定下来。
- **分页**：按当前视口尺寸与字体设置计算每页容量；字体设置变更时重新分页并保持阅读位置。
- **进度存储**：本地存储（localStorage / IndexedDB）保存书名、阅读位置、阅读设置；不依赖任何服务端。
- **样式**：统一使用 CSS 变量定义主题，为将来加入深色主题预留（届时只需增加一组变量）。

## 5. 迭代路线

- **V0（MVP）**：上表 P0 功能，跑通核心闭环。
- **V1.1**：正则切分章节（"第X章"）+ 目录跳转；深色主题。
- **V1.2**：书签、全文搜索。
- **更远**：EPUB 支持、TTS 朗读、云同步等。

## 6. MVP 验收标准

1. 导入 UTF-8 与 GBK 编码的 TXT 均正常显示，无乱码。
2. 百万字级长篇可流畅打开与翻页。
3. 关闭后重新打开，能自动回到上次阅读位置。
4. 进度条拖动可准确跳转到对应位置。
5. 字号 / 行距调整后即时生效，且不丢失阅读位置。
