# xifeng 阅读 · V6.4 划词翻译方案

> 需求：**划线选词翻译**，面向"读英文书"这个真实场景（英文书 → 中文）。

## 1. 场景与约束

| 约束 | 说明 |
| --- | --- |
| 纯本地优先 | 阅读本体不依赖服务端；翻译是本项目**第一个需要联网**的功能，必须可关、可降级 |
| 不打断阅读 | 选词即出结果，浮卡贴在选区旁；不跳页、不弹窗、不阻塞翻页 |
| 隐私 | 只把**选中的那一段**发出去；不整本上传、不记录阅读内容 |
| 离线可用 | 没网 / 接口挂了：明确提示"翻译服务不可用"，其余功能一切照旧 |

## 2. 翻译来源（实测选型）

| 方案 | 实测结果 | 结论 |
| --- | --- | --- |
| Google `translate_a/single`（非官方接口） | **429 Too Many Requests**（服务端按 IP 限流，本机直接被拒） | ❌ 不可靠，不上生产 |
| LibreTranslate 公共实例 | `libretranslate.com` 403、`terraprint.co` 502、`lt.vern.cc` 证书过期 | ❌ 公共实例全挂 |
| 自建 LibreTranslate | 需要用户自己部署 + API key | ⛔ 与"本地优先"冲突，不做默认 |
| **MyMemory** `api.mymemory.translated.net` | ✅ 200，返回中文；**CORS `Access-Control-Allow-Origin: *`**；匿名单次上限 **500 字符**；超限返回 200 但正文是 `QUERY LENGTH LIMIT EXCEEDED` 错误串 | ✅ 默认启用（需处理 500 字符切分与错误串） |

**方案**：默认走 MyMemory，**长文本按句切成 ≤ 450 字符的多段并发请求**再拼回去；
预留 `translateWith(customFn)` 接口，用户以后想接自己的服务时不用改调用方。

## 3. 交互设计

```
选中英文 ──→ 浮动工具栏（既有）多一个「译」按钮
                              │
                              ▼
                    ┌─────────────────────┐
                    │ 原文（最多 3 行，可展开）
                    │ ─────────────────── │
                    │ 译文（流式：先出"翻译中…"）
                    │ ─────────────────── │
                    │ 复制译文 · 存为想法   ✕
                    └─────────────────────┘
```

- **选词**（1~3 个词）时额外显示**逐词释义**（MyMemory 不提供词性/音标，
  所以只给"这个词的译文"，不假装是词典）；
- **选句/段**时只给整段译文；
- 「存为想法」：把译文写进这条划线/批注的 note（复用 V4.0 的想法字段），
  于是译文能随批注一起导出 Markdown；
- 同一段文字再次选中时命中**内存缓存**，不重复发请求（含失败缓存，避免反复打挂接口）。

## 4. 语言方向

- 自动判断方向：选中文本里 ASCII 字母占多数 → 译为中文；CJK 占多数 → 译为英文；
- 目标语言可在设置里固定（`auto` / `zh-CN` / `en`），默认 `auto`；
- 语言判断是纯函数（`detectDirection`），可单测。

## 7. 单词翻译的坑与对策（实测）

机器翻译对**孤立单词**几乎不可用 —— MyMemory 给的多是"词源/构形义"：

| 选中 | 接口返回 | 读者要的 |
| --- | --- | --- |
| beginning | 源 | 开始 |
| running | 运行 | 跑 |
| bank | 银行 | 岸（Alice 坐在河岸上） |
| reading | 阅读 | ✅ 恰好对 |

三条对策（都在 `core/translate.ts`，可单测）：

1. **本地兜底义 `WORD_GLOSSES`**：动名词/分词（-ing 那批）接口必给词源义，
   直接用本地常见义替换；多义词（bank / wonder）保留接口结果，把本地义项作为
   「也作：…」并列展示 —— 不替读者做取舍。
2. **整句语境对照**：只要"这个词可能译得不对"（退化或另有义项），就再发一次
   **它所在整句**的翻译，在浮卡里以「整句」小字给出。
   实测：beginning 的整句译文"爱丽丝开始厌倦了坐在她姐姐旁边"，语境一看就懂。
3. **不假装是词典**：不给音标/词性/例句 —— MyMemory 没有这些数据，
   硬凑只会骗人。要词典级释义应接专门的词典 API（见 §5 的 `fetchImpl` 注入口）。
