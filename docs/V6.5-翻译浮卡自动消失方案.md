# xifeng 阅读 · V6.5 翻译浮卡"移开即消失"方案

> 需求：划词翻译出结果后，**鼠标移到其他文本上时，原来的译文自动消失**，
> 不需要再去点浮卡右上角的 ✕。

## 1. 现状与问题

V6.4 的浮卡（`.translate-card`）只有三条关闭路径：点 ✕、按 Esc、再选新词翻译。
结果就是：查完一个词想继续读，浮卡一直悬在正文上挡着字，**必须抬手去点那个小叉**——
在"读英文书时频繁查词"这个高频场景里，这一步很烦。

## 2. 为什么不能"鼠标一离开就消失"

最直觉的实现（指针离开浮卡就关）会立刻坏掉：

1. **点完「🌐 译」的一瞬间，指针本来就停在浮卡外面**（它停在浮动工具栏原来的位置上，
   而工具栏在点击后已经收起）。指针没动，卡却"离开即消失"——译文还没看清就没了。
2. 用户想点「复制译文 / 存为想法」，**手要移到卡内**，途中会短暂离开卡片区域。

所以"移开"必须由**三个条件**共同判定，缺一不可：

| 条件 | 常量 | 作用 |
| --- | --- | --- |
| 浮卡已出现一小段时间 | `ARM_DELAY_MS = 600` | 避开"刚点完译、指针还在卡外"的误判 |
| 指针**真的移动过**（累计位移 ≥ 12px） | `MOVE_EPSILON_PX = 12` | 手抖/轻微漂移不算"我要走了" |
| 指针停在卡外**并停下** ≥ 500ms | `HOVER_SETTLE_MS = 500` | 移动过程中不消失；停下来了才收起 |

再配上**点击正文即消失**（最无歧义的一条），两条路径合起来覆盖真人操作。

## 3. 判定规则（完整）

浮卡在这些时刻关闭，均调用同一个 `closeTranslate()`：

| 触发 | 说明 |
| --- | --- |
| **点击/拖动正文** | `main` 的 mousedown：开始新的选字 = 明确表示"上一个查完了" |
| **鼠标移开并停下** | 上述三条件同时满足（本版新增，主诉求） |
| 滚动正文 | 已经在往下读，浮卡没有意义 |
| 翻页 / 进度条跳转 / 目录·书签跳转 | 位置变了，旧译文对应不上 |
| 原版 ↔ 文字视图切换 | 同上 |
| 打开阅读菜单 | 菜单要占屏，避免叠层 |
| 按下 Esc | 既有行为 |
| 再次划词翻译 | 新请求作废旧请求（既有行为） |

**不会**关闭的情况：指针停在浮卡内部（含「复制译文 / 存为想法 / ✕」按钮），
或浮卡出现后指针始终没动（用户在专心读译文）。

## 4. 实现落点

| 文件 | 职责 |
| --- | --- |
| `src/core/dismiss.ts`（新） | 纯函数：`shouldAutoDismissHover` + `isSignificantMove` + 常量，可单测 |
| `src/pages/ReaderPage.tsx` | 一个 `pointermove` 监听维护"最后一次显著移动时刻"，用 120ms 轮询落地判定；把 `closeTranslate()` 接到点击/滚动/翻页/跳转/菜单/切视图等入口 |
| `src/pages/Translator.tsx` | 不变（仍保留 ✕ 与 Esc 作为显式关闭） |

为什么用"指针移动时刻 + 定时轮询"而不是"移动事件里直接判断"：
判定条件里的"停下 500ms"本身就是时间条件，光靠事件触发不了；
轮询间隔 120ms 远小于 500ms 阈值，误差可以忽略，而且比给每个入口挂离开事件简单可靠。

## 5. 边界与取舍

- **触屏**：手指点击正文 = mousedown 路径，同样会关；手指拖动（pointermove）也计入移动。
  触屏没有"悬停"，但用户点别处就关，体验一致。
- **浮卡挡住正文**：这不是本方案的问题（它仍会浮在选区上方），
  但"移开鼠标就能收掉"让遮挡变得可以随手解决。
- **误关的代价低**：重新划一次词即可，缓存命中时是瞬间出结果（V6.4 已做内存缓存）。
- **不做的事**：不做"自动淡出/超时自动关闭"——用户在读译文时卡片不该自己消失；
  消失的触发权必须来自用户的动作。

## 6. 验收

- [x] 划词翻译出结果后，把鼠标移到别的段落并停住 → 浮卡自动消失；
- [x] 划词翻译出结果后**不动鼠标**持续读译文 → 浮卡不消失；
- [x] 手从工具栏移向「复制译文」按钮的途中，浮卡不消失；
- [x] 移动鼠标但幅度很小（≤ 5px 抖动）→ 不消失；
- [x] 在正文任意处按下鼠标（准备重新选字）→ 浮卡立即消失；
- [x] 滚动 / 翻页 / 拖进度条 / 开菜单 / 切视图 → 浮卡消失；
- [x] 指针停在浮卡内部读译文 → 不消失；
- [x] 全部单测（271 例）与 `tsc` 通过。

## 7. 实测（浏览器，1280×720，英文文档 *Debugging I2C*）

| 场景 | 期望 | 实测 |
| --- | --- | --- |
| 译文出结果后 1.5s 内不动鼠标 | 不消失 | ✅ 仍在 |
| 鼠标移到别的段落并停下 | 自动消失 | ✅ 1.01s 内收起（0.5s 停顿 + 轮询） |
| 在原位置做 ≤5px 抖动 | 不消失 | ✅ 仍在 |
| 指针移进浮卡内部 | 不消失 | ✅ 仍在 |
| 在正文别处按下鼠标 | 立即消失 | ✅ |
| 滚动正文 | 消失 | ✅ |
| 按 → 翻页 | 消失 | ✅ |

消失后重新划词即恢复，且 V6.4 的内存缓存让同一段译文**瞬间**再出（无网络往返）。
