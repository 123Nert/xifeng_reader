# xifeng 阅读 · V6.3 书架封面方案（每本书的第一页）

> 需求：书架上每本书都要**一眼认得出**。现在全是渐变色块 + 书名，长的像两本不同的书
> 也分不出来。要求把**每本书的第一页**做成封面 —— 无论是 TXT 还是 PDF。

## 1. 设计目标

| 目标 | 说明 |
| --- | --- |
| 一眼认出 | 封面 = 这本书打开后的第一页，不是装饰性色块 |
| 全格式覆盖 | TXT / MD / HTML / EPUB / PDF 都有封面；EPUB 自带封面时优先用真封面 |
| 不拖慢导入 | 封面生成失败绝不影响导入成功（best-effort，失败退回渐变色块） |
| 老书也补上 | 库里已导入的书在进入书库时后台补齐，不用重新导入 |
| 存储可控 | 单张封面 ≈ 400×560 的 JPEG/PNG，几十 KB 量级 |

## 2. 各格式的"第一页"从哪来

| 格式 | 第一页来源 | 生成方式 |
| --- | --- | --- |
| **PDF** | 原版第 1 页 | 复用 V6.2 的 `pdfFiles` 原件 + pdf.js 按封面尺寸渲染一页 |
| **TXT / MD / HTML** | 正文开头一段 | 纯计算排版 + canvas 画成"纸页"样式（与阅读页同一套字体栈） |
| **EPUB** | 书里自带的封面图 | 有就用（原样缩到封面尺寸）；没有则退回正文第一页 |
| 老记录（V6.1 扫描版） | 库里已存的第 1 页位图 | 缩放到封面尺寸即可，不用重新解析 PDF |

## 3. 文本封面怎么画（TXT / MD / HTML）

真实的书页长什么样，就画成什么样：

```
┌──────────────────────┐
│  ← 9% 边距           │
│  第一章 山中旧信      │  ← 标题：首行短句，或开头的章节标题行；字号 ×1.25 加粗
│                      │
│  暮色四合时，山道上   │  ← 正文：全角字号 = 位图宽 × 4.5%
│  走来一个旅人。       │     行高 1.7，全角按 1 字宽、半角按 0.55 折行
│  他抬头望了望天，     │
│  ...                 │  ← 放不下就截断，末行加省略号
└──────────────────────┘
```

- 位图固定 `400 × 560`（= 5:7，与 `.book-cover` 的宽高比一致），卡片上显示约 158px 宽，
  2.5 倍余量足够清晰；
- 纸页底色 `#fdfbf5` + 一圈极淡描边，和阅读页的日间主题同色系；
- 排版参数由 `coverLayout(width)` 纯函数给出，可单测：
  每行字数 = 内容宽 ÷ 字号，行数 = 内容高 ÷ 行高。

### 三条"别把封面画歪"的规则（`coverExcerpt`）

网文 TXT 的正文开头千奇百怪，这三条是从真实样本里踩出来的：

1. **紧挨着的重复段落折叠掉**：分页会把跨页内容再贴一遍，同一段紧跟两遍 ——
   桌面只有一屏，重复段会白占半行。（只折叠**紧邻**的重复；
   对话里的重复（「你来了。」/「我来了。」）是正常写法，不能碰。）
2. **正文前连排的章节标题跳过**：一批 TXT 的正文就是"第1回 / 正文 / 第2回 / 正文…"，
   若原样画，封面会变成目录页（实测：西遊記的封面曾是第1回~第10回）。
   规则是"跳过开头的标题行，取紧随其后的正文"。
3. **取到下一章标题就收尾**：正文只有一段（草稿本、网页摘录这种短文本）时，
   也不能因为"到下一章了"就空着 —— 先保证有正文，再考虑止步。

## 4. 生成时机

1. **导入时**：拿到正文/原件就顺手生成，随书一起入库（进度提示"生成封面…"）。
2. **进书库时补齐**：对没有封面的老书，按顺序一本本生成（同时只跑一本，
   避免几十本书一起开 pdf.js 把主线程压住），生成一张就更新一张，界面立刻能看到。
3. **失败不重试**：本书会话内记下尝试过的 id，失败的本子保持渐变色块，不反复啃。

## 5. 代码落点

| 文件 | 职责 |
| --- | --- |
| `src/core/cover.ts`（新） | 摘录 / 折行 / 版面参数（纯函数，单测）+ canvas 绘制（薄层） |
| `src/core/pdfOriginal.ts` | 新增 `renderPdfFirstPage(bytes, width)`：开→渲染第 1 页→销毁 |
| `src/core/bookRepository.ts` | 新增 `setBookCover(id, cover)` |
| `src/pages/LibraryPage.tsx` | 导入时生成 + 进库补齐 + 卡片渲染真封面 |
| `src/styles/theme.css` | `.book-cover.has-image` 的图片铺法与底色 |

## 6. 验收

- [x] 五个格式各导入一本，卡片上都能看到"第一页"而不是色块；
- [x] PDF 封面与打开后的第 1 页一致（同源渲染，同一份 pdf.js）；
- [x] 老书（无封面）进入书库后自动补齐，生成一张写一张；
- [x] 封面生成失败时导入仍然成功，退回渐变封面；
- [x] 封面宽高比 = 5:7，卡片上不拉伸、不裁掉正文首行；
- [x] 全部单测（222 例）与 `tsc` 通过。

## 7. 实测（浏览器，1280×720）

| 书 | 格式 | 封面来源 | 结果 |
| --- | --- | --- | --- |
| 封面验证-1page | PDF | 原件第 1 页 | 导入时即生成，与阅读页首屏一致 |
| scan-reimport / sample-scan-only | PDF（扫描） | 原件第 1 页 | 在 1280×720 下仍能看清图与表 |
| sample-cn-reimport | PDF | 原件第 1 页 | 章标题与正文原样呈现 |
| 山中旧信 | EPUB | 书内自带封面 | 深绿真封面 |
| 山行记 | EPUB | 无自带封面 → 正文首段 | 画成书页（标题 + 正文 8 行） |
| 草稿本 / 网页摘录 | MD / HTML | 正文首段 | 短文本也能取到正文，不再空白 |
| 风雨夜行 / 西遊記 | TXT | 正文首段 | 首章标题 + 一段正文（不再画成目录页） |
| sample-cn | PDF（V6.0 时代，无原件） | 退回正文首段 | 卡片仍有时封面，不会空着 |

封面体积：7–60 KB/本（400×560 JPEG，质量 0.9）。
